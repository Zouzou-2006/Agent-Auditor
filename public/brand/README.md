# Agent Auditor brand

| File | Use |
|---|---|
| `agent-auditor-mark.svg` | The icon alone: favicon (`app/icon.svg` is a copy), app icon, slide corners |
| `agent-auditor-logo-dark.svg` | Full logo on dark backgrounds (dashboard, video) |
| `agent-auditor-logo-light.svg` | Full logo on light backgrounds (README, submission page) |
| `agent-auditor-logo-preview.png` | All versions side by side |

The mark: a shield (the control layer) with a check (every payment is audited) whose stroke ends in
the agent's node. Colors match the dashboard: cyan `#22d3ee` → emerald `#34d399` on `#06080b`.
The full logo's text uses Inter / the system font; convert it to outlines before using it in video or print.
